# 💫 About Me

👋 Hi! I'm **Lilit**, a Data Scientist based in Yerevan, Armenia. I work at **Liga Insurance** while finishing my final year in Artificial Intelligence at the National Polytechnic University of Armenia 🎓.

My day-to-day is classification, regression, and time-series modeling on real-world insurance and healthcare data — work where careful feature engineering, model interpretability, and clean data structures matter more than chasing the latest architecture.

### 🛠️ What I work on

- **Predictive modeling** with gradient boosting (XGBoost, LightGBM) and tree-based methods
- **Time-series forecasting** and interval-based behavioral analysis
- **Feature engineering** and building model-ready datasets, metadata mappings, and data dictionaries
- **NLP** using OpenAI APIs and classical text approaches (from earlier roles at Melon AI and Smart Code)

### 🧪 Tech Stack

- **Languages:** Python (Primary), SQL, C++
- **ML/DL:** Scikit-learn, XGBoost, LightGBM, TensorFlow, PyTorch
- **Data:** Pandas, NumPy, Matplotlib, Seaborn
- **Workflow:** Git, GitHub, Jupyter

### 📚 Currently learning

- AI/ML program at **Picsart Academy** (2025–2026)
- MLOps fundamentals and end-to-end model deployment
- Production-grade Python and ML engineering practices

### 🚀 Goal:
I am driven by curiosity and a commitment to building AI that benefits society. I value integrity, teamwork, and the continuous pursuit of innovation 🏆.
